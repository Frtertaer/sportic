# CS2-аналитик

Киберспортивный бот с рабочего стола (`Desktop\openrouter`). Перенесён сюда целиком как отдельный проект, не внутрь футбольного `SportsBot`.

Здесь исходники `cs2_*`, сканер Winline, live/prematch edge, дашборд `redesign_v2`, снимок `prod_snapshot_20260711` и скрипт деплоя на DE-сервер (`de_ssh.py`). Сессия Winline лежит в `winline_auth.json` — это логин, его содержимое не копировать в чат.

На столе файлов с `cs2` / `winline` в имени больше нет. Копия тех же скриптов всё ещё есть в `D:\develop\openrouter` — её не трогал.
